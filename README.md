# YaLegendCo design files

Print-ready PNGs (4500x5400, transparent) for the YaLegendCo Etsy shop, hosted here so Gelato can download them by public link when creating products.

Files live at `designs/<YYYY-MM-DD>/<slug>_print.png`. Raw link pattern:
`https://raw.githubusercontent.com/0078fayis/yalegendco-designs/main/designs/<date>/<slug>_print.png`

All designs © YaLegendCo. Not licensed for reuse.

## Landing page tests

`landing/build.py` builds three test landing pages (Backyard Rules, SuperOnTime, SelfStrata) into `landing/sites/<slug>/`, each a static site for Netlify with a Netlify Forms sign-up.
